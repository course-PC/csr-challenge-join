# CSR challenge: join

**[Join the challenge →](https://github.com/course-PC/csr-challenge-join/issues/new?template=join.yml)**

1. One member per group opens the join issue, listing the GitHub usernames of the other members (at most 3 members in total) and the course code given in class.
2. A private repository `csr-<username>` is created for the group within a minute, and every member is invited to it. The bot replies on the issue with the link.
3. Every member accepts the invitation (e-mail, or the link in the reply) within 7 days.
4. Clone the repository, read its README, fill in the group header in `my_kernel.cu`, push.

Request rejected (typo, wrong code)? Fix it and open a new issue. Group created with the wrong members? Contact the instructors.
